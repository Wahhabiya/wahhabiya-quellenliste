# Wahhābīya – Quellenbibliothek

Enthält zwei **getrennte** Sammlungen:

- `index.html`: ursprünglicher bibliografischer Export mit **718 Datensätzen** und 19 Spalten. Standardmäßig werden alle 718 angezeigt. Die Daten sind aus der bereitgestellten ursprünglichen HTML-Datei übernommen.
- `forschung.html` mit `daten.json`: **1.043** historische Forschungseinträge aus den beiden Excel-Dateien, nicht mit einzelnen Büchern gleichzusetzen.

## Installation auf GitHub Pages

Alle vier Dateien in das Hauptverzeichnis des bestehenden Repositorys hochladen. `index.html` ersetzt die bisherige Startseite; `daten.json` kann ersetzt werden. `forschung.html` ist neu. Bestehende Dateien zunächst behalten und vor dem Ersetzen sichern.

## Einschränkungen

718 bibliografische **Datensätze** bedeuten nicht 718 eindeutig verschiedene Bücher. Mindestens fünf Verfasser-Titel-Kombinationen sind doppelt. Die früher gemeldeten rund 50 fehlenden Bücher konnten ohne eine autoritative Soll-Liste noch nicht einzeln ermittelt werden. Externe Quellenlinks und Angaben zum Prüfstatus wurden nicht neu verifiziert.
